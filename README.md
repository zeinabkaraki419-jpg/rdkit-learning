# 🧬 RDKit Learning

My learning journey with RDKit — an open-source cheminformatics toolkit for working with molecular data using Python. 📌

---

## 📌 About
This repository documents my progress learning RDKit, including notes, code examples, and small exercises exploring molecular representation, structure manipulation, and chemical data analysis. 🎯

---

## 🎯 Goals
* Understand RDKit's core data structures (`Mol` objects, SMILES/SMARTS parsing)
* Explore molecular descriptors and fingerprints
* Practice substructure searching and similarity analysis
* Visualize molecules and reactions
* Build small practical projects using RDKit 🚀
